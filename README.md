# Zyntra

Sistema de gestión de envíos de una paquetería con sede en Honduras: envíos nacionales, internacionales y express.

Proyecto integrador de Ingeniería de Software II, Universidad Anáhuac Mayab.

Esta es la versión inicial (v0.1): una sola clase `Envio` concentra los datos, el cálculo del costo y los cambios de estado.
